# Kleiderspender Portal

Projekt für den Kurs IPWA01-01 (Programmierung von Webanwendungsoberflächen) an der IU Internationale Hochschule.

Das Portal ermöglicht es, eine Kleiderspende online zu registrieren. Spendende wählen dabei selbst aus, in welches Krisengebiet ihre Spende gehen soll. 
Es handelt sich um einen clientseitigen Prototyp im Rahmen einer Fallstudie. Es gibt kein Backend und keine dauerhafte Datenspeicherung.

## Ausführung
`index.html` im Browser öffnen. Für die Entwicklung wurde die VS-Code-Erweiterung Live Server verwendet. Eine Installation oder ein Build-Prozess ist nicht erforderlich, Bootstrap wird über ein CDN eingebunden.

## Technologien
- HTML5
- CSS über Bootstrap 5
- Vanilla JavaScript (ohne Framework)
