# kleiderspenden-portal

Projekt für den Kurs IPWA01-01 (Programmierung von Webanwendungsoberflächen) an der IU Internationale Hochschule.

Das Portal ermöglicht es, eine Kleiderspende online zu registrieren. Spendende wählen dabei selbst aus, in welches Krisengebiet ihre Spende gehen soll.

## Technologien
- HTML5, CSS
- Bootstrap 5
- Vanilla JavaScript
